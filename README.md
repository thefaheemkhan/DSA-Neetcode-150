# NeetCode 150 🚀

My personal practice repository for solving the [NeetCode 150](https://neetcode.io/practice) — a curated list of 150 essential coding interview problems covering all major data structure and algorithm patterns.

This repo contains my solutions, notes, and progress tracker as I work through the list for interview preparation.

## 📌 About

- **Goal:** Solve all 150 problems, understand the underlying patterns, and be interview-ready.
- **Languages:** Python (primary) — feel free to swap in your own.
- **Structure:** Each problem lives in its own file inside the relevant category folder, with the approach, time/space complexity, and any notes.

## 🎯 How I'm Using This Repo

1. Pick a problem from the tracker above.
2. Attempt it cold (timeboxed, ~25–35 min) before looking at hints.
3. Write the solution in the matching category folder.
4. Add a short note on the pattern/insight used — useful for quick review before interviews.
5. Check off the box above and commit.

### Interview Practice Tips
- Revisit solved problems after a few days (spaced repetition) instead of only moving forward.
- Group by pattern, not just by solving order — e.g. do all Sliding Window problems back-to-back to internalize the template.
- Practice explaining the approach out loud (as in a real interview) before coding.
- Track time taken per problem to measure improvement over time.
